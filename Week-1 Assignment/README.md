# XYZ Bank - Diwali Coupon System

JavaScript case study project for EPAM-LNCT Project Development Program (Week 1).

## What it does

XYZ Bank wants to give Diwali coupons to existing customers. This page handles it:

- Shows a welcome message, with a popup alert on mouseover
- Register button hides the instruction steps
- Enter Customer ID → validate it → generate coupon code

## How to use

1. Open `CaseStudy-XYZ bank.html` in a browser
2. Enter a Customer ID that contains "XYZ" (e.g. `XYZ123`)
3. Click Validate customer
4. Click Generate coupon

## Note

`document.write()` is used to show results, so it replaces the whole page content when you click the buttons. That's expected, not a bug.
